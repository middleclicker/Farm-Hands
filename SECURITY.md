# Security policy

The latest version on `main` is the supported version. Older commits and forks are not maintained as separate releases.

Please report a vulnerability through [GitHub's private vulnerability reporting form](https://github.com/middleclicker/Farm-Hands/security/advisories/new). Include reproduction steps, affected browser or platform, impact, and a possible fix if you have one. Do not include secrets or personal data in the report.

The maintainer will review private reports and coordinate a fix and disclosure. There is no guaranteed response or patch timeline. Please avoid opening a public issue or pull request with exploit details before a fix is available.
